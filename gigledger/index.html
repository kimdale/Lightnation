Local mode

Data safety

Local mode saves to this browser only, not your GitHub repository or other devices. Back it up regularly. To enable cloud sync, run supabase/schema.sql in your own Supabase project before signing in. Only the publishable/anon key belongs in the browser; never paste a service-role key. Cloud sync uses last-write-wins, so avoid simultaneously editing on two devices.
